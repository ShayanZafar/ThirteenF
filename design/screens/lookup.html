Method

Funds holding counts the 13F filings that list Shopify for each quarter end, as compiled by 13f.info from SEC 13F-HR filings. A manager can file more than one report, so read it as a close count of funds, not an exact one.

Shares and value exclude options and are rounded the way the source gives them; a change of 0 means no change at that rounding. Value moves with Shopify’s share price, so a lower value does not by itself mean funds sold.

The watchlist median is the middle change in funds holding across the eight stocks on your watchlist for the same period. Every Dec 31 the count jumps for most stocks because newly large funds file their first 13F, so compare with the median rather than with zero.

13F covers managers with $100M or more in US-listed securities, and long positions only. Late filings can still add a few funds to the latest quarter.
