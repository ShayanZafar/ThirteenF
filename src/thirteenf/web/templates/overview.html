Method

Funds holding counts the managers whose 13F-HR report for each quarter end lists shares of the stock, from the SEC’s Form 13F data sets. Each manager counts once, with amendments applied; options and bond principal are left out.

Vs typical compares each stock’s change in funds holding with the typical stock’s: the middle change across every stock held by at least 100 funds in both periods{% if latest_period.typical_count("stock") %} ({{ fmt.count(latest_period.typical_count("stock")) }} in {{ latest_period.label }}){% endif %}. An ETF is compared with the typical ETF. Every Dec 31 most stocks gain funds as newly large managers file their first 13F, so compare with the typical change rather than with zero.

Your watchlist is kept on this computer in data/watchlist.csv. It started from the example list in config/watchlist.csv.

13F covers managers with $100M or more in US-listed securities, and long positions only. Filings made after {{ fmt.day(latest_period.data_through) }} arrive in the SEC’s next data set, so late filers can still add a few funds to the latest quarter.
